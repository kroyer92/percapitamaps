# Per Capita Maps Studio – Privacy Policy

Last updated: 6 November 2026

Per Capita Maps Studio ("the tool") is a private tool operated by the owner of the YouTube channel
"Per Capita Maps" (@PerCapitaMaps). It uploads videos to, and reads analytics for, that one channel only.
It has no other users and no public sign-in.

## YouTube API Services

The tool uses the YouTube API Services. By using the tool, the user agrees to be bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the
[Google Privacy Policy](https://policies.google.com/privacy).

## What data the tool accesses

Through the YouTube API Services, and only for the owner's own channel:

- channel and video metadata (video IDs, titles, descriptions, playlists),
- the videos the owner uploads,
- the owner's own comments posted under those videos,
- public comments that viewers post under the owner's videos (comment text, the commenter's public
  display name and the time), so the tool can suggest a reply that the owner then posts by hand,
- view, watch-time and similar statistics from YouTube Analytics.

No other data about any other YouTube user or channel is collected.

## How the data is used

The data is used only to publish the owner's videos and to show the owner which of their videos perform well,
for example the median views per video format. Viewer comments are only read to suggest replies to the owner: they are processed on the owner's
server, shown only to the owner in the tool's private Telegram chat, and never sent to an AI provider or any other service.

Weekly review (only when the owner switches it on; off until the YouTube API compliance review is complete): once a week the tool makes a summary of the owner's own video statistics and the metrics derived from them (views, engaged views, average percentage viewed, likes, shares, subscribers gained, per video, with the owner's own video titles). The owner reviews this summary with Anthropic's AI assistant Claude to decide which videos to make next. The summary contains no comments and no information about any viewer. Anthropic's handling of it is described in the [Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy).

Apart from that weekly summary, the data is never sold, shared with third parties, or used for advertising.

## Storage and deletion

- Data is stored on a private server controlled by the owner.
- Video statistics and the metrics derived from them are kept for at most 36 months, then deleted.
- Other data obtained from the YouTube API Services (such as video titles, descriptions and viewer comments) is refreshed or deleted within 30 days.
- All stored data obtained from the YouTube API Services is deleted within 30 days after access is revoked, or on request.

## Cookies and devices

The tool runs only on the owner's server. It does not place cookies. The one public page, the Per Capita Nation passport page (below), keeps a random code and the visitor's vote choice in the visitor's own browser storage, so it can show their passport and their vote; nothing else is stored on any visitor's device.

## Revoking access

Access can be revoked at any time on the Google security settings page:
[https://myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Per Capita Nation passport page

Per Capita Nation is a game on the channel: viewers can join a made-up country on a web page run by
the owner. It does not use the YouTube API Services or any YouTube data; nobody is added from
comments or channel data.

- What is stored: the name the visitor types and the country they pick, with their citizen number
  and the time they joined, and their vote in the page's daily poll. No email, no login, no tracking.
- Where it is shown: on the page, and possibly in the channel's daily census video on YouTube and
  Instagram (the visitor agrees to this with a tick box before joining).
- Abuse protection: a salted one-way hash of the visitor's internet address, kept 2 days for
  sign-ups, and for votes until the question is decided, then deleted. It cannot be turned back into the address.
- Deletion: the "Leave the nation" button deletes the passport at once; anyone can also ask by
  email or in a comment. Videos already published are not changed.
- Country figures come from the World Bank (CC BY 4.0).
