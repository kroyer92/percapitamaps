# Per Capita Maps Studio – Privacy Policy

Per Capita Maps Studio is a private tool operated by the owner of
the YouTube channel "Per Capita Maps" (@PerCapitaMaps). It uploads videos to, and reads
analytics for, that one channel only.

- Data accessed: the owner's own YouTube channel metadata, uploads
  and analytics, via the YouTube API Services.
- No data from any other user is collected, stored or shared.
- Data is stored on a private server controlled by the owner and
  is never sold or shared with third parties.
- The tool uses YouTube API Services. See the YouTube Terms of
  Service (https://www.youtube.com/t/terms) and the Google Privacy
  Policy (https://policies.google.com/privacy).
- Access can be revoked at any time at
  https://myaccount.google.com/permissions.

Contact: percapitamaps@gmail.com
