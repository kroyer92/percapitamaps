# Per Capita Maps Studio

Per Capita Maps Studio is a private tool that uploads videos to, and reads analytics for, the YouTube channel
[Per Capita Maps (@PerCapitaMaps)](https://www.youtube.com/@PerCapitaMaps). It is used only by the channel owner and has no other users.

## Uses YouTube API Services

This tool uses the **YouTube API Services** (YouTube Data API and YouTube Analytics API) to:

- upload finished videos to the owner's own YouTube channel and add them to playlists,
- post the owner's own first comment under each video,
- read view and watch-time statistics for the owner's own videos.

By using this tool, the user agrees to the [YouTube Terms of Service](https://www.youtube.com/t/terms).
